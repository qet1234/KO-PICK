# 오늘어디 Google Play Console 입력값

기준일: 2026-08-13

이 문서는 현재 Android 앱 코드와 개인정보처리방침을 기준으로 Play Console 입력 시 사용할 값을 정리한 운영용 초안입니다. 실제 Console 질문 문구가 변경되면 의미가 같은 항목에 맞춰 입력합니다.

## 기본 정보

- 앱 이름: 오늘어디
- 패키지명: `com.koreapick.app`
- 출시 대상: Android / Google Play
- 배포 형식: Android App Bundle (`.aab`)
- 대상 API: Android 16 / API 36
- 광고 포함 여부: 아니요
- 앱 내 구매/결제: 없음
- 로그인: 선택 사항 (비회원 핵심 탐색 가능)

## 공개 정책 URL

- 개인정보처리방침: `https://koreapick.duckdns.org/privacy`
- 계정 삭제 안내: `https://koreapick.duckdns.org/account-deletion`
- 이용약관: `https://koreapick.duckdns.org/terms`
- 고객지원: `https://koreapick.duckdns.org/support`

## 앱 액세스

핵심 장소 탐색과 추천은 로그인 없이 이용 가능합니다. 저장/계정 동기화 같은 회원 기능은 카카오, 네이버, Google 소셜 로그인으로 이용합니다. 별도의 사내 계정이나 초대 코드가 필요한 앱이 아닙니다.

Play 검토자에게 별도 테스트 ID/비밀번호를 제공할 필요가 없는 구조입니다. 단, Play Console이 제한된 로그인 기능에 대한 설명을 요구하면 다음 취지로 기재합니다.

> 핵심 기능은 로그인 없이 이용할 수 있습니다. 선택형 계정 기능은 공개 소셜 로그인으로 접근할 수 있으며 별도의 전용 테스트 자격 증명이 필요하지 않습니다.

## 데이터 보안 입력 기준

### 수집하지 않는 데이터

- 정밀 위치
- 연락처
- 사진/동영상
- 카메라
- 마이크
- 광고 ID를 이용한 교차 앱 추적 데이터
- 결제/금융 정보
- 건강/피트니스 정보
- SMS/통화 기록

### 회원 기능 사용 시 처리

소셜 로그인 사용자가 제공자 화면에서 허용한 범위에서 다음 정보를 처리할 수 있습니다.

- 제공자 고유 식별자
- 이메일
- 이름/닉네임
- 프로필 이미지(제공된 경우)

목적:
- 앱 기능 / 계정 관리
- 로그인 및 동일 사용자 식별
- 저장/최근 기록 동기화

보유:
- 원칙적으로 회원탈퇴 시까지

### 서비스 개선 데이터

이 데이터는 별도 선택 동의 후에만 수집하며 기본값은 미동의입니다.

- 무작위 방문자 UUID
- 검색 조건 및 검색 결과 없음 여부
- 장소 조회/지도/길찾기/예약/저장 등 앱 상호작용
- 화면 경로
- 기기 플랫폼
- 로그인 여부
- API 응답시간/상태코드
- 앱 오류 메시지

목적:
- 분석
- 앱 기능/품질 개선
- 장애 및 성능 진단

보유:
- 생성일부터 90일
- 이용자가 앱에서 동의를 철회할 수 있음

### 보안/접속 로그

서비스 제공 과정에서 서버/호스팅 계층이 다음 정보를 제한적으로 처리할 수 있습니다.

- IP 주소
- 사용자 에이전트
- 요청 시각
- 인증/오류/보안 기록

목적:
- 보안
- 부정 이용 방지
- 장애 대응

개인정보처리방침 기재 기준 보유기간은 원칙적으로 90일이며 법적 의무나 보안 사고 대응이 필요한 경우 필요한 범위에서 별도 보존할 수 있습니다.

## 데이터 처리 확인 질문

Play Console의 데이터 보안 질문에는 다음 기준을 유지합니다.

- 전송 중 데이터 암호화: 예 (HTTPS/TLS)
- 계정 삭제 요청 제공: 예
- 앱 내부 계정 삭제 경로: 예 (`내 계정 > 회원탈퇴`)
- 앱 외부 계정 삭제 경로: 예 (`/account-deletion`)
- 개인정보 판매: 아니요
- 광고 목적 데이터 공유: 아니요
- 선택형 서비스 개선 데이터 수집 거부 가능: 예

## 위치 권한

현재 Android 앱은 `expo-location`을 사용하지 않으며 앱 코드에서 위치 런타임 권한을 요청하지 않습니다. 장소의 공개 좌표는 TourAPI/장소 데이터의 지도 표시를 위한 장소 정보이며 사용자의 현재 위치 데이터가 아닙니다.

## 콘텐츠 및 대상 사용자

서비스는 장소/맛집/카페/관광/축제 추천 및 지도 연결 서비스입니다. 현재 가입 과정에서 만 14세 이상 확인을 요구합니다. 어린이를 주 대상으로 설계한 서비스가 아닙니다.

정확한 연령 타겟 선택은 Play Console의 실제 대상 사용자 설정과 스토어 설명을 일치시켜야 합니다.

## 계정 삭제 정책

앱 내부의 `내 계정 > 회원탈퇴`에서 계정 삭제를 시작할 수 있고, 외부 웹의 `/account-deletion`에서도 삭제 절차를 안내합니다. 계정 삭제 시 계정과 삭제 대상 사용자 데이터를 제거하며 법령상 또는 보안상 보존 의무가 있는 데이터가 있으면 개인정보처리방침에 기재된 범위만 보존합니다.

## 테스트 트랙

개인 개발자 계정이 2023-11-13 이후 생성된 신규 개인 계정에 해당하면 Production 접근 신청 전 비공개(Closed) 테스트 요구사항을 충족해야 합니다. Google Play의 현재 기준은 최소 12명의 테스터가 연속 14일 이상 opt-in 상태를 유지하는 것입니다.

권장 순서:
1. 내부 테스트에 AAB 등록
2. 핵심 흐름 확인
3. 비공개 테스트 구성
4. 해당 계정에 테스트 의무가 적용되면 12명/14일 조건 충족
5. Production access 신청
6. Production 제출
